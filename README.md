# Projeto inteligencia-artificial

# Sobre o projeto

Projeto desenvolvido durante uma aula com o objetivo de praticar HTML e CSS por meio da construção de uma página web proposta pelo professor.

O desafio consistiu em reproduzir a interface apresentada em aula utilizando conceitos de estruturação de páginas, posicionamento de elementos, estilização e organização do conteúdo, aplicando exclusivamente HTML e CSS.

A aplicação é composta por três páginas distintas, permitindo exercitar a navegação entre páginas e a construção de layouts estáticos de forma consistente.

# Como executar o projeto

## Pré-requisitos

* Navegador Web (Google Chrome, Microsoft Edge, Firefox, etc.)
* Visual Studio Code (opcional)

## Clonar o repositório

```bash
git clone git@github.com:soleralucas/inteligencia-artificial.git

cd inteligencia-artificial
```

## Executando a aplicação

Abra o arquivo:

```text
index.html
```

em qualquer navegador web.

Caso deseje visualizar ou editar o código-fonte, o projeto também pode ser aberto normalmente no Visual Studio Code utilizando a extensão Live Server.
